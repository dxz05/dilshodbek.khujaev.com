Thanos sort

National Olympiad · National Selection to IOI 2024 original (uzbek) ↗ solve ↗

Thanos's sorting algorithm refers to the following procedure:

  • If the array is sorted in non-decreasing order*, Thanos does nothing.
  • Otherwise, using the infinity stones, Thanos splits the array in two equal halves and erases either half.
  • He keeps doing this until the array is sorted.

You have an array \(a[1], a[2], \dots, a[N]\) of length \(N\). You are also given \(Q\) queries, each with numbers \(l\) and \(r\). Your task is to find the minimum number of times the infinity stones must be used to sort the subarray \(a[l], a[l+1], \dots, a[r]\). It is guaranteed that the length of the given subarray is a power of two.

*In non-decreasing order, every element must be no smaller than the one before it. That is, \(a[1] \le a[2] \le \ldots \le a[N]\).

Input

The first line contains \(N\) and \(Q\) — the number of elements and queries.
The second line contains \(a[1], a[2], \dots, a[N]\) — the array elements.
The next \(Q\) lines each contain \(l\) and \(r\) — the queries.

Output

Print the answer for each query on its own line — \(Q\) lines in total.

Example

For example, let \(N = 9\), \(a = [3, 1, 4, 1, 5, 9, 2, 6, 5]\) and \(Q = 3\).

In the first query \(l = 1\) and \(r = 8\), i.e. we want the minimum number of operations for the array \(a' = [3, 1, 4, 1, 5, 9, 2, 6]\). In the first operation we erase the left half of the array, giving \(a' = [5, 9, 2, 6]\). Suppose in the second operation we erase the right half. Then \(a' = [5, 9]\), which is sorted in non-decreasing order. Since we used 2 operations, the answer is \(2\).

In the second query \(l = 5\) and \(r = 5\). Since the array \(a' = [5]\) is already sorted, no operations are needed.

input 
9 3
3 1 4 1 5 9 2 6 5
1 8
5 5
3 4
output 
2
0
1

Constraints

  • \(1 \le N \le 131\,072\)
  • \(1 \le Q \le 200\,000\)
  • \(1 \le a[i] \le 10^9\), for all \(1 \le i \le N\)
  • \(1 \le l \le r \le N\), and \(r - l + 1 = 2^x\), where \(x\) is a non-negative integer

Subtasks

  1. (6 points) In all queries \(r = l + 1\)
  2. (13 points) \(N \le 8\); \(Q = 1\); \(l = 1\); \(r = N\)
  3. (21 points) \(Q = 1\); \(l = 1\); \(r = N\)
  4. (24 points) The answer for every query does not exceed \(2\).
  5. (15 points) \(N \le 16384\)
  6. (21 points) No additional constraints.
